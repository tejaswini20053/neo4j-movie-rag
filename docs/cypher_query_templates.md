# Cypher Query Templates

Reusable, parameterised templates used or generated by the RAG app.
`$param` placeholders are filled in by the app (or by you, in Neo4j Browser).

## 1. Find a movie's director(s)
```cypher
MATCH (p:Person)-[:DIRECTED]->(m:Movie)
WHERE toLower(m.title) = toLower($title)
RETURN p.name AS director
```

## 2. Find all movies a person acted in
```cypher
MATCH (p:Person)-[:ACTED_IN]->(m:Movie)
WHERE toLower(p.name) = toLower($name)
RETURN m.title AS movie, m.released AS year
ORDER BY m.released
```

## 3. Find co-actors (people who acted with a given person)
```cypher
MATCH (a:Person)-[:ACTED_IN]->(m:Movie)<-[:ACTED_IN]-(costar:Person)
WHERE toLower(a.name) = toLower($name)
RETURN DISTINCT costar.name AS costar, m.title AS sharedMovie
```

## 4. Full cast + crew of a movie
```cypher
MATCH (m:Movie {title: $title})
OPTIONAL MATCH (actor:Person)-[r:ACTED_IN]->(m)
OPTIONAL MATCH (director:Person)-[:DIRECTED]->(m)
RETURN m.title AS movie,
       collect(DISTINCT actor.name) AS cast,
       collect(DISTINCT director.name) AS directors
```

## 5. Movies released within a year range
```cypher
MATCH (m:Movie)
WHERE m.released >= $startYear AND m.released <= $endYear
RETURN m.title AS movie, m.released AS year
ORDER BY m.released
```

## 6. Top-rated movies by review
```cypher
MATCH (:Person)-[r:REVIEWED]->(m:Movie)
RETURN m.title AS movie, r.rating AS rating, r.summary AS summary
ORDER BY r.rating DESC
LIMIT $limit
```

## 7. Shortest connection path between two people ("Bacon number" style)
```cypher
MATCH path = shortestPath(
  (a:Person {name: $nameA})-[:ACTED_IN*]-(b:Person {name: $nameB})
)
RETURN [n IN nodes(path) | coalesce(n.name, n.title)] AS path
```

## 8. Recommend movies: "people who liked X also acted with..."
```cypher
MATCH (m:Movie {title: $title})<-[:ACTED_IN]-(actor:Person)-[:ACTED_IN]->(rec:Movie)
WHERE rec.title <> m.title
RETURN rec.title AS recommendation, count(actor) AS sharedActors
ORDER BY sharedActors DESC
LIMIT 5
```

## 9. Schema introspection (used to ground the LLM before generation)
```cypher
CALL db.labels() YIELD label RETURN label;
CALL db.relationshipTypes() YIELD relationshipType RETURN relationshipType;
CALL db.propertyKeys() YIELD propertyKey RETURN propertyKey;
```
